# Brand copywriting

Goal: a voice the brand can keep, and the core copy that expresses it. Output in `copy/`, voice summary in
`.brand/brand.md` → Voice.

**Write in the brand's market language(s)**, which may differ from the language the designer is chatting in. Ask if
unclear. For multilingual brands, write natively in each language rather than translating literally, and flag
puns or idioms that don't travel.

## 1. Tone of voice guide (`copy/voice.md`)

- **Voice in one line** — "We talk like a sharp, kind expert friend."
- **3–4 principles**, each with: what it means, a **do** example, a **don't** example, and how it flexes by context.
- **Tone flex** — the voice stays, the tone shifts: e.g. marketing (more energy), support (calmer), errors (plain,
  helpful, no jokes), legal (clear, still human).
- **Vocabulary** — words we use, words we avoid (jargon, clichés, competitor language), house style (capitalisation,
  numbers, dates, emoji, Oxford comma, formal/informal address — e.g. *tu/Lei*, *du/Sie*, *tú/usted*).
- **Before / after** — rewrite 3 real or typical sentences in the new voice.

## 2. Core copy

Produce in this order, each as options + recommendation:

1. **Tagline** — 8–12 options across styles (benefit, attitude, imperative, wordplay, descriptive), then shortlist
   3 with rationale. Check: short, ownable, true, works next to the logo, not a cliché ("Innovation for you",
   "Quality since…"), not already a well-known slogan, works in all target languages.
2. **Descriptor** (if the name doesn't explain the offer) — "Brand — independent coffee roasters".
3. **Boilerplate** — 25, 50 and 100 words.
4. **Elevator pitch** — one sentence.
5. **Brand story / manifesto** (optional) — 150–300 words; specific, not inflated.
6. **Website core** — homepage hero (headline + sub + CTA), value propositions, about page.
7. **Social bios** — per platform within character limits.
8. **Microcopy samples** — buttons, empty states, errors, confirmations (if digital).

## 3. Quality bar

- **Specific beats grand.** Replace adjectives with facts and images.
- **The competitor test:** if a competitor could sign the line, rewrite it.
- **No AI-sounding filler:** avoid stacked triads, "not just X but Y", "elevate", "unlock", "seamless",
  "in today's fast-paced world", rhetorical questions as openers, empty superlatives.
- **Rhythm:** read it aloud; vary sentence length.
- **Claims:** flag anything needing substantiation or regulated wording (health, finance, environment/green
  claims, comparatives).
- Self-evaluate with rubric C before showing.

## 4. Copy audit (Evaluate mode)

For existing copy: score with rubric C, then give a line-by-line table: original → issue → rewrite. Keep the
designer's good lines; don't rewrite for the sake of it.
