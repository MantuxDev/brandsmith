# Logo Lab for Adobe Illustrator

Runs the Logo Lab on your selection. No AI, no account, nothing uploaded.

## Use
1. Select the logo (or nothing, to test everything on the artboard).
2. **File → Scripts → Other Script…** and pick `LogoLab.jsx`.
3. The report opens in your browser; the PDF and PNG buttons work as usual.

To keep it in the **File → Scripts** menu, copy `LogoLab.jsx` into Illustrator's `Presets/<language>/Scripts` folder and restart Illustrator.
